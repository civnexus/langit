# Mount Paradise

An eight-page cinematic concept website for a proposed mountain community in Trawas, East Java.

Public site: https://langit-three.vercel.app/index.html
Repository: https://github.com/civnexus/langit

## Edit and preview

Dependency-free HTML, CSS and JavaScript. Run `python3 -m http.server 8765` from this directory for a local preview.

Content is maintained in `scripts/pages.py`, `scripts/tiers.py` and `scripts/clubhouse.py`, with shared templates in `scripts/build.py`. After changes, run `python3 scripts/build.py` and commit generated HTML alongside the sources. Styles and interactions are in `styles.css` and `site.js`.

## Current pages

Home, Vision, Clubhouse, Private Lodges, Lodge Comparison, Garden Lodge, Mountain Living and The Land.

Mountain Cabins form the entry category, followed by Retreat, Family, Reserve and Estate lodge tiers. Eight designs are shown in total. Plot sizes, room counts, pricing and final specifications remain in development.

The Clubhouse is the social heart of Phase 2, with a restaurant/bar, mountain patio, relaxed café, lounges and valet arrival for weddings and private events. The pool garden connects it to a separate Recreation Pavilion (gym and tennis) and a quieter Spa Pavilion. Membership terms remain in development. The Vision page offers a concise visual overview and links to the dedicated Clubhouse page.

## Artwork

Published pages now use cinematic artwork throughout. The original promotional watercolor and Forest Lodge watercolor are no longer referenced; their original asset files remain as archival material. Existing cinematic artwork is preserved. New original generated images: `clubhouse.jpg`, `clubhouse-spa.jpg`, `mountain-cabin.jpg` and `forest-cinematic.jpg`. Generation briefs are recorded in `CINEMATIC-REVISION.md`.

All visuals are concepts. Phase 1 is the existing built pilot; Phase 2 covers 10 hectares; Phase 3 is a future expansion opportunity of 20+ hectares. Renderings do not establish final plots, guaranteed views or approved facilities.
