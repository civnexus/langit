# Mount Paradise

Vision-led static destination website for Trawas, East Java.

Build: `python3 scripts/build.py`
Check: `python3 scripts/check.py`
Preview: `python3 -m http.server 8765`

Current editorial content is in `scripts/vision_revision.py`, executed after the historical source modules to preserve residence data. Shared navigation, metadata, footer and redirects are built by `scripts/build.py`. Nine active pages; former URLs redirect to consolidated chapters.

Use `SITE_URL=https://mountparadisejava.com python3 scripts/build.py` once the custom domain is connected. Until then canonical and sharing URLs use the working Vercel host.

Direct email only: general enquiries to info@mountparadisejava.com; residence sales to sales@mountparadisejava.com. No facility booking flows.

See DESTINATION-DIRECTION.md for brand, architectural and landscape direction. New scenes are illustrative concepts; Arvorest imagery awaits replacement with real photographs.
