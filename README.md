# Mount Paradise

A six-page architectural concept website for a proposed mountain community in Trawas, East Java.

Live site: https://civnexus.github.io/langit/

## Edit and preview

The site is dependency-free HTML, CSS and JavaScript. Open `index.html` directly, or run `python3 -m http.server 8765` from this directory and visit http://localhost:8765.

Page content is maintained in `scripts/build.py`. After changing it, run `python3 scripts/build.py`. Styles and interactions are in `styles.css` and `site.js`. Commit the generated HTML alongside source changes. GitHub Pages serves the root of `main`.

## Artwork

The user-approved cinematic image and original watercolor are preserved as `assets/signature-lodge.jpg` and `assets/original-watercolor.jpg`. The original model villa reference is `assets/original-veranda.jpg` (source PNG also retained). Four additional original concept artworks were made with the built-in Imagegen tool: `vista.jpg`, `interior.jpg`, `evening.jpg`, and `masterplan.jpg`. See `ART-DIRECTION.md` for the prompt set. All assets are local; no stock image services or external scripts are used.

Renderings and the watercolor community layout are conceptual. They do not establish surveyed boundaries, guaranteed views, plot counts, floor plans, approved amenities or completed construction. Area 1 is approximately 8–10 hectares; Area 2 is a future expansion opportunity of 20+ hectares.
